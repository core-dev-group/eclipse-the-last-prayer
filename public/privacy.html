Kebijakan Privasi

Pembaruan Terakhir: 1 Agustus 2026

1. Pendahuluan

Core Dev Group ("kami") menghormati privasi Anda dan berkomitmen untuk melindungi data pribadi pengguna ("Anda"). Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan menjaga informasi Anda saat Anda mengakses atau mengunduh *The Nameless King* ("Aplikasi") serta layanan terkait kami, termasuk server komunitas Discord.

2. Data yang Kami Kumpulkan

Sebagai game berformat APK yang beroperasi sebagian besar secara *offline* atau dengan fitur *online* terbatas, kami tidak mengumpulkan data pribadi sensitif (seperti nama asli, alamat, atau nomor kartu kredit). Namun, kami mungkin mengumpulkan:
- Data Perangkat: Model perangkat, versi sistem operasi, dan laporan kerusakan (crash logs) untuk keperluan perbaikan *bug*.
- Data Bot Discord: Jika Anda menggunakan fitur integrasi komunitas kami, bot kami mengumpulkan User ID Discord publik Anda untuk keperluan pemberian peran (roles) dan pencatatan statistik (Leaderboard).

3. Penggunaan Data

Data yang kami kumpulkan semata-mata digunakan untuk:
- Memperbaiki kinerja Aplikasi dan stabilitas server.
- Menyediakan layanan fitur komunitas (seperti pemberian role *Beta Tester* otomatis).
- Mencegah kecurangan (cheating) dan penyalahgunaan eksploitasi dalam sistem game.

4. Keamanan Data

Kami mengimplementasikan standar keamanan wajar untuk melindungi informasi Anda. Core Dev Group tidak akan pernah menjual, menyewakan, atau memperdagangkan data analitik perangkat maupun ID Discord Anda kepada pihak ketiga mana pun.

5. Tautan Pihak Ketiga

Aplikasi atau situs web kami dapat berisi tautan ke pihak ketiga (seperti Discord). Segala informasi yang Anda berikan kepada pihak ketiga diatur sepenuhnya oleh Kebijakan Privasi mereka sendiri.

6. Hubungi Kami

Jika Anda memiliki pertanyaan mengenai Kebijakan Privasi ini atau ingin mengajukan permohonan penghapusan data Anda dari sistem Bot Discord kami, silakan hubungi tim dukungan kami melalui server Discord resmi *The Nameless King*.
